# Translation packs

English (`en.po`) and French (`fr.po`) translations of THE SCREAMER's text, for OpenScreamer. The engine loads
them as described in [`spec/13-options-host.md`](../spec/13-options-host.md#translations).

## Format

gettext PO, one entry per string. No original text is included: each key is `sha1:` and the first 16 hex
digits of the SHA-1 of the original string's bytes, as the game prints them. A `#:` comment says where the
original string is.

| Context | Key | Text |
|---|---|---|
| `game` | a string of MAIN2HDE.EXE, B01, or a monster's name in `Gnn` | the translation, with the game's markup (`_` or `~` new line, `#` a number), in ASCII and the accented lowercase letters the game's font gets (à â ä é è ê ë î ï ô ö ù û ü ÿ ç; accented capitals are shown plain) |
| `demo` | a string of DEMO2HDE.EXE | the same; it keeps the original's number of line breaks |
| `keyword` | a conversation keyword in B01 | the words a player may type for it, separated by `\|` |
| `password` | the bar's password | what a player may type instead |

Lines are at most the width given in each entry's `#. width` comment (39 characters for most messages; items in
command menus at most 11).

They are generated by the spec side's tools from the earlier port's translations.
